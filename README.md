# todo-priority-app
# ✅ Todo App — Gestion de tâches avec priorités

Une application de gestion de tâches construite avec React, TypeScript et Vite.  
Les tâches peuvent être classées par priorité (Urgente, Moyenne, Basse), filtrées,  
sélectionnées en lot et supprimées. Les données persistent via le `localStorage`.

## ✨ Fonctionnalités

- Ajout de tâches avec niveau de priorité
- Filtrage par priorité (Tous / Urgente / Moyenne / Basse)
- Sélection multiple et suppression en lot
- Persistance des données (localStorage)
- Interface responsive avec DaisyUI + Tailwind CSS

## 🛠️ Stack technique

- React 19 + TypeScript
- Vite
- Tailwind CSS v4 + DaisyUI v5
- Lucide React (icônes)

## 🚀 Lancer le projet

\`\`\`bash
npm install
npm run dev
\`\`\`

Ouvre [http://localhost:5173](http://localhost:5173) dans ton navigateur.
